# Rotondwa Gift Madi — Portfolio

Light IT / programmer-style portfolio website.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Structure (sections, layout) |
| `styles.css` | All styling (colours, grid, terminal look) |
| `script.js` | Terminal animation, projects, skills, references, nav highlight |

## How to edit

1. **Text / contact** → edit `index.html` (About, Experience, Contact).
2. **Projects, skills, references, terminal lines** → edit the data arrays at the top of `script.js`.
3. **Colours / fonts / layout** → edit CSS variables in `:root` inside `styles.css`.

## Preview

Open `index.html` in a browser (all three files must stay in the same folder).

## Deploy (GitHub Pages)

1. Create a repo (e.g. `Rotondwa-glitch.github.io` or any repo).
2. Upload these three files.
3. Settings → Pages → deploy from main branch root.
4. Site will be live at your Pages URL.

## Stack

- HTML5
- CSS3 (custom properties, grid, sticky header)
- Vanilla JavaScript (no frameworks)
